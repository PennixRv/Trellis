# 解决方案设计与收敛

当 `current_phase_id` 为 `solution_design_and_convergence` 时使用。阅读本 Skill 同目录的 `workflow.md`，核对当前有效的需求基线和阶段 2 决策空间或跳过记录。

本阶段锁定当前路线所依据的决定和方案，不代表实施已获授权。需用户决定时，使用 `pennix-decision-grill` 同步询问并留在阶段 3；实施路线须形成 `implementation_contract`，再单独取得实施批准后才能进入阶段 4。触发 prior-art review 的方案须在阶段结果接受前完成该审查。
